# Quy ước thuật ngữ ROS 2

Giữ nguyên tên chuẩn trong cột đầu khi viết nội dung và dùng alias trong wikilink khi ngữ pháp tiếng Việt cần thiết.

| Tên chuẩn | Alias được dùng |
| --- | --- |
| ROS | ROS (Robot Operating System), ROS framework |
| Node | node |
| Publisher | publisher |
| Subscriber | subscriber |
| Topic | topic |
| Service | service |
| Client | client, service client, action client |
| Action | action |
| Parameter | parameter |
| Message | message |
| Interface | interface, ROS Interface |
| Package | package |
| Workspace | workspace |
| Launch file | launch file |
| Callback | callback |
| Executor | executor |
| QoS | Quality of Service |
| Middleware | middleware |
| rosbag | ROS bag, bag |
| turtlesim | turtle simulator |
| rqt_console | rqt console |

Các command, code, API, đường dẫn và tên package giữ nguyên theo tài liệu chính thức.
